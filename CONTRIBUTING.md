# Contribuir

¡Gracias por mejorar GTA IV LATAM AI Dubber!

1. Crea un *fork* y una rama desde `main`.
2. No incluyas audio, archivos RPF, modelos, registros ni otros recursos de GTA IV.
3. Instala el entorno de desarrollo con `python -m pip install -e ".[test]"`.
4. Ejecuta `python -m pytest -q` antes de enviar el cambio.
5. Explica qué cambia, cómo lo probaste y qué GPU/WSL utilizaste cuando sea relevante.

Los adaptadores para otros motores de voz son bienvenidos si conservan las garantías
de publicación atómica, duración, canales y *fallback* seguro del proyecto.
